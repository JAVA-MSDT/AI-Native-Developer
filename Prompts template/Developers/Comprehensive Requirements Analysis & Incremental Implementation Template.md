# Comprehensive Requirements Analysis & Incremental Implementation Template

## Template Summary

This template is designed for intensive and comprehensive analysis of any set of requirements, with a focus on edge cases, risk assessment, and incremental implementation planning. It is structured to be reusable for code reviews, feature planning, or architectural changes, and includes clear instructions, stepwise breakdowns, and actionable findings. The template also supports incremental HTML output or similar deliverables.

---

## Prompt

I have the following requirements:

- [Insert requirements here] *(make this generic for any domain or project)*

Please perform an intensive and comprehensive analysis that covers all edge cases and possible scenarios related to these requirements.

Your analysis should include:

1. **Step-by-step walkthrough and in-depth explanation** of each requirement.
2. **Analysis of:**
   - The relevant code base and similar patterns.
   - All implementations affected by these requirements.
   - Specific areas of the code that will be impacted by the changes.
   - Potential risks, including the possibility of breaking existing functionality, and strategies to avoid such issues.
   - Any edge cases, scenarios, or possible implementations that may not be immediately obvious.
3. **Suggestions for dividing the implementation into incremental, logical steps**, so that each step can be independently verified and committed.
4. **For each finding, provide:**
   - The issue or observation.
   - The suggested fix or approach.
   - The impact of this fix on other parts of the codebase, if any.

---

## Output Specification

- Clear, organized instructions.
- Explicitly requests edge case and risk analysis.
- Specifies output format (e.g., HTML, Markdown, or other as needed).
- Requests both findings and an incremental implementation plan.

---

## Incremental Implementation Plan (Example for HTML/Other Deliverables)

To address latency or complexity in finalizing deliverables (e.g., HTML, code, documentation), break down the task into clear, manageable steps:

1. Create the basic skeleton or structure (e.g., HTML, code module).
2. Apply necessary styling or configuration.
3. Add findings or features incrementally, one at a time.
4. After each addition, review to ensure all findings are included and context is preserved.
5. Continue this process until all findings are incorporated and verified.

By following this step-by-step approach, you can finalize deliverables efficiently and accurately.
