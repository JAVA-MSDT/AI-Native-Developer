# Prompt Template Generator

## Template category

**Category:** Meta-Prompting & Automation Tool

- This template generates a comprehensive, production-ready prompt template for future use based on a verified successful AI response, standardizing instructions, constraints, and required parameters into a downloadable format.

---

## prompt

`Act as an elite prompt engineer and system architect. I will provide you with a successful response/result that was previously verified as correct. Your task is to analyze that successful result and create a generic, reusable prompt template based on it, following the exact markdown structure provided in the context. The final prompt template generated by this workflow MUST instruct the AI to provide its output as a downloadable Markdown (.md) file to prevent syntax loss or truncation.`

**Prompt details:**

- **Dynamic Input Context:** Paste the verified good AI response or the specific asset details (e.g., "The Polish B1 Roadmap HTML response") into the input section.
- **Design Ethos:** Structural framework division using uppercase markers, explicit constraint boundaries, and boolean instructions to eliminate ambiguity.

**Instructions:**

- **Analyze the Success Path:** Deconstruct the verified good output to isolate the exact structural, stylistic, and technical elements that made it successful.
- **Formulate the Generic Prompt:** Translate those successful parameters into an actionable instructions block containing standard `[VARIABLE_PLUGS]` for future runs.
- **Integrate File Generation Logic:** Explicitly add an instruction stating that the final asset must be compiled and delivered as a downloadable Markdown (.md) file using internal scripting capabilities to avoid cut-offs.

**Constraints:**

- **No Inline Text Leakage:** The generated prompt block must remain perfectly clean, using brackets for placeholders without spilling raw descriptive text outside its layout.
- **Mandatory File Output Flag:** The resulting prompt must force the system to deliver a downloadable document rather than a standard chat window text stream.
- **Strict Format Preservation:** Ensure all brackets, markdown signs, and variable definitions are correctly closed and mapped.

**Required Output:**

- A self-contained prompt framework structured strictly under the `# Title`, `## Template category`, `## prompt`, `Template Name:`, and `Is it worth it?` markdown headers, packaged inside a downloadable Markdown file.
